# meatfish.biz.id

Website statis responsif Meatfish untuk katalog frozen food dan program kemitraan. Konten dan desain dibuat original; tidak menyalin aset atau teks situs referensi.

## Menjalankan

```powershell
python -m http.server 8080
```

Buka `http://localhost:8080` bila dijalankan dari folder ini.

## Sebelum publikasi

- Tambahkan nomor WhatsApp resmi dan redirect pada `assets/main.js`.
- Isi alamat serta wilayah layanan.
- Ganti contoh testimoni dengan ulasan terverifikasi.
- Konfirmasi katalog, harga, paket, dan ketentuan pengiriman.
- Tambahkan logo/foto produk milik Meatfish atau aset berlisensi.

Tidak ada proses build; dapat langsung dipasang di GitHub Pages, Cloudflare Pages, atau hosting statis.
